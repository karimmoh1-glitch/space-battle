About

Space Battle is a tournament where autonomous bots fight in an arena. This site is Mission Control: the game sends every match result here, and the leaderboard updates on its own within 5 seconds.

Why the board looks like this

The leaderboard gets projected for pit crews and the crowd, so we designed it to be read from far away in a few seconds:

  • Top 3 first. The podium is the biggest thing on the screen because that's what people look for.
  • Best match by default. We compared ranking by best match, total and average. Total punishes teams that get fewer matches, and average punishes one bad crash, so best match is the fairest default. Staff can switch if the event needs it.
  • Show what changed. Arrows, NEW tags, flashing rows and the latest results list let people see what just happened without reading the whole table.
  • No reloading. The page asks the server for new scores every 5 seconds and only changes the numbers, so the screen doesn't blink.
  • Team pages. Click any team to see every match it played and a chart of its scores, so pit crews can check their own results.
  • No double counting. If the game sends the same match twice, the match_id makes sure it only counts once.
  • Big Screen mode. /display hides the menu, uses bigger text, always uses the dark space theme, and scrolls the latest results across the bottom.
  • Tools for staff. The hidden admin page can fix scores, merge misspelled team names, undo deletes, post announcements, lock the final results and download a backup.
