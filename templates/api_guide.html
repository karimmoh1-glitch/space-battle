Report a match

Send each match result to one address. It appears on the board within seconds.

Submit a result

POST /api/results

FieldTypeRequiredMeaning
nametextYesTeam name, 1 to 40 characters.
scoreintegerYesSigned whole number. Usually -100 to 500, but no range is enforced.
submissionIdtextNoYour own ID for this match. Makes retries safe.
 
curl -X POST {{ request.url_root }}api/results \
  -H "Content-Type: application/json" \
  -d '{"name": "Nova Squad", "score": 250}'

Responses

StatusMeaning
201Result saved.
200Same submissionId, name and score as before. Nothing was added.
400Invalid JSON or fields. The error explains what to fix.
409submissionId already used with a different name or score.
413Request is larger than 10 KB.
503The database is unavailable. Safe to retry.
 
{
  "ok": true,
  "duplicate": false,
  "result": { "id": 12, "name": "Nova Squad", "score": 250, "createdAt": "2026-11-14T15:04:05.000+00:00" }
}

Repeated requests

Two matches can have the same score, so identical requests count as separate matches. If your system might retry after a network error, include a submissionId. A repeat with that ID is recorded only once, even when both copies arrive at the same moment.

Read the standings

GET /api/leaderboard returns teams, the 10 most recent matches, and statistics as JSON.
