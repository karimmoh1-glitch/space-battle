API Guide

The match system sends each result to the leaderboard with a POST request to /api/results, with a JSON body: 

{
  "name": "Nova Squad",
  "score": 250
}

Example with curl

curl -X POST {{ request.host_url }}api/results \
  -H "Content-Type: application/json" \
  -d '{"name": "Nova Squad", "score": 250}'

Get the leaderboard

GET /api/leaderboard returns every team as JSON, best first.

Fields

Field Rules
name Required. Text, 1 to 40 characters.
score Required. A whole number. Can be negative.

Responses

Status Meaning
201 Saved.
400 Something is wrong with the request. The error field says what.
413 The request is bigger than 10 KB.
503 The database is down. Try again.
