API Guide

The match system sends each result to the leaderboard with a POST request to /api/results, with a JSON body: 

{
  "name": "Nova Squad",
  "score": 250
}

Example with curl

curl -X POST {{ request.host_url }}api/results \
  -H "Content-Type: application/json" \
  -d '{"name": "Nova Squad", "score": 250}'

What you get back

{
  "ok": true,
  "result": { "id": 12, "name": "Nova Squad", "score": 250, "created_at": "2026-11-14 15:04:05" }
}

Get the leaderboard

GET /api/leaderboard returns every team as JSON, in rank order. Each team has rank, name, best, total, average and matches.

GET /api/live returns everything the leaderboard page shows: the teams, the latest results, the ranking mode, the announcement and whether results are locked.

Fields

Field Rules
name Required. Text, 1 to 40 characters. Extra spaces are removed, and capital letters don't matter.
score Required. A whole number (not "250" or 250.5). Can be negative.

Responses

Status Meaning
201 Saved.
400 Something is wrong with the request. The error field says what.
423 Results are locked because the tournament is over. Nothing was saved.
413 The request is bigger than 10 KB.
503 The database is down. Try again.
