API Guide

The match system sends each result to the leaderboard with a POST request.

Send a result

POST /api/results with a JSON body:

{
  "name": "Nova Squad",
  "score": 250
}
FieldRules
nameRequired. Text, 1 to 40 characters.
scoreRequired. A whole number. Can be negative.

Example with curl

curl -X POST {{ request.host_url }}api/results \
  -H "Content-Type: application/json" \
  -d '{"name": "Nova Squad", "score": 250}'

Responses

StatusMeaning
201Saved.
400Something is wrong with the request. The error field says what.
413The request is bigger than 10 KB.
503The database is down. Try again.

Get the leaderboard

GET /api/leaderboard returns every team as JSON, best first.
